# 🧳 Campine — کمپینه

پلتفرم دوزبانه (فارسی/انگلیسی) رزرو سفر با لیدرهای حرفه‌ای — ساخته‌شده با **Next.js 14** و **Prisma**.

> مسافر سفر و لیدر را انتخاب می‌کند → درخواست رزرو اولیه ثبت می‌شود → لیدر تأیید/رد می‌کند →
> پس از تأیید، پرداخت از طریق درگاه زرین‌پال انجام و رزرو قطعی می‌شود.

---

## ✨ امکانات

### 🌗 ظاهر و زبان
- **حالت روز/شب برای همه صفحات** — پیش‌فرض بر اساس ساعت کاربر به‌صورت خودکار؛ با انتخاب دستی کاربر در تمام صفحات ذخیره می‌شود
- **دوزبانه فارسی/انگلیسی** با جهت RTL/LTR و تغییر زبان از هر صفحه
- **جستجوی دو بخشی سفرها:** بر اساس تاریخ + نام سفر / لیدر / مقصد

### 🤝 همکاری به‌عنوان لیدر
- فرم **«درخواست جهت همکاری»** برای لیدرها و مجریان تور (ثبت‌نام عمومی فقط برای مسافران است)
- **بارگذاری مدارک:** تصویر کارت ملی/شناسنامه (الزامی) + مجوزها و گواهی‌نامه‌ها (اختیاری، چند فایل)
- صفحه **مدارک مورد نیاز همکاری** با فهرست کامل فایل‌های موردنیاز
- بررسی درخواست‌ها و مدارک پیوست‌شده توسط مدیر و **ساخت خودکار حساب لیدر** پس از تأیید

### 🧑‍💼 لیدر
- ثبت سفر با مشخصات کامل (عنوان، مقصد، تاریخ، قیمت، ظرفیت، خدمات، تصویر — فارسی و انگلیسی)
- **گردش کار سفر:** پیش‌نویس → ارسال برای تأیید مدیر → تأیید → **بارگذاری (انتشار) توسط لیدر** → انجام‌شده
- مشاهده لیست سفرهای خود + بخش جداگانه **سفرهای انجام‌شده**
- بررسی درخواست‌های رزرو مسافران: **تأیید یا رد** (با یادداشت)
- دریافت **نظر و امتیاز (۱–۵ ستاره)** از مسافران پس از پایان هر سفر
- چاپ صفحات پنل در هر زمان

### 🎒 مسافر
- مشاهده سفرها و پروفایل لیدرها + **جستجوی لیدر بر اساس نام**
- مشاهده **امتیاز و نظرات مسافران** در پروفایل هر لیدر
- جستجو و فیلتر
- انتخاب سفر/لیدر و ثبت **درخواست رزرو اولیه** (بدون پرداخت)
- مشاهده وضعیت: در انتظار لیدر ← تأیید/رد ← **پرداخت** ← قطعی
- پرداخت امن از طریق **درگاه زرین‌پال** (یا حالت آزمایشی Mock)
- **برگه رزرو قابل چاپ** با کد پیگیری، مبلغ و کد رهگیری پرداخت

### 👨‍💻 مدیر
- مشاهده و دسترسی کامل به اطلاعات **همه سفرها** و **همه رزروها**
- **تأیید یا رد** سفرهای ارسال‌شده توسط لیدرها (شرط انتشار سفر)
- **لغو سفر** (با دلیل — رزروهای فعال نیز لغو می‌شوند)
- **منع لیدر از سفر** (حذف لیدر از سفر + امکان تعیین لیدر جدید)
- مدیریت کاربران: تغییر نقش، **تعلیق/رفع تعلیق** حساب
- داشبورد آماری (کاربران، سفرها، رزروها، درآمد)

### 🌐 عمومی
- **دوزبانه فارسی/انگلیسی** با پشتیبانی کامل RTL/LTR (تغییر با یک کلیک)
- طراحی واکنش‌گرا (موبایل، تبلت، دسکتاپ)
- **چاپ بهینه** همه صفحات پنل (دکمه چاپ + استایل مخصوص پرینت)
- احراز هویت امن (JWT + bcrypt) و پنل اختصاصی برای هر نقش

## 🚀 اجرا

```bash
# 1. نصب وابستگی‌ها
npm install

# 2. ساخت دیتابیس + داده‌های نمونه
npm run db:reset

# 3. اجرای سرور
npm run dev          # توسعه — http://localhost:3000
# یا
npm run build && npm run start   # تولید
```

## 🔑 ورود آزمایشی (با شماره موبایل + کد پیامکی)

ورود و ثبت‌نام **بدون رمز عبور** و با **شماره موبایل + کد تایید پیامکی** انجام می‌شود.
ثبت‌نام مسافر نیازمند **تصویر کارت ملی/شناسنامه** است. لیدرها از طریق فرم **«درخواست جهت همکاری»** درخواست می‌دهند و پس از تأیید مدیر، حساب لیدر برایشان ساخته می‌شود.

| نقش | شماره موبایل |
|------|----------------|
| مدیر | `09121234567` |
| لیدر | `09121112233` |
| لیدر | `09124445566` |
| مسافر (دارای رزرو تأییدشده در انتظار پرداخت) | `09359876543` |
| مسافر | `09351234567` |

> در **حالت نمایشی** (بدون `KAVENEGAR_API_KEY`) کد تایید روی صفحه و در کنسول سرور نمایش داده می‌شود.

## 📱 پیکربندی پیامک (کاوه‌نگار)

در فایل `.env`:

```env
# خالی یا "mock" => حالت نمایشی (کد در صفحه نمایش داده می‌شود)
KAVENEGAR_API_KEY="your-kavenegar-api-key"
KAVENEGAR_SENDER="100086633"
```

## 💳 پیکربندی پرداخت (زرین‌پال)

در فایل `.env`:

```env
# برای حالت آزمایشی (بدون درگاه واقعی):
ZARINPAL_MERCHANT_ID="mock"
ZARINPAL_SANDBOX="true"

# برای اتصال واقعی:
ZARINPAL_MERCHANT_ID="xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
ZARINPAL_SANDBOX="false"     # true برای sandbox زرین‌پال
```

- حالت **Mock**: کاربر به یک درگاه شبیه‌سازی‌شده هدایت می‌شود و می‌تواند پرداخت موفق/ناموفق را تست کند.
- حالت **واقعی**: کاربر به درگاه بانکی زرین‌پال منتقل می‌شود؛ تراکنش پس از بازگشت **verify** و سپس رزرو قطعی می‌شود.

> نکته: برای استقرار نهایی، `NEXT_PUBLIC_APP_URL` را به آدرس دامنه خود تغییر دهید و `SESSION_SECRET` قوی تنظیم کنید.

## 🗂 معماری

```
campine/
├── prisma/
│   ├── schema.prisma        # مدل‌ها: User, Trip, Booking, Payment
│   └── seed.ts              # داده‌های نمونه
├── src/
│   ├── middleware.ts        # گارد احراز هویت مسیرهای /panel
│   ├── lib/
│   │   ├── auth.ts          # نشست JWT + bcrypt
│   │   ├── db.ts            # کلاینت Prisma
│   │   ├── zarinpal.ts      # درگاه زرین‌پال (واقعی + Mock)
│   │   ├── format.ts        # قالب‌بندی تاریخ (جلالی) و مبلغ
│   │   ├── i18n/            # دیکشنری فارسی/انگلیسی
│   │   └── actions/         # Server Actions (auth, trips, bookings, admin)
│   ├── components/          # کارت سفر، پوسته پنل، دکمه چاپ و ...
│   └── app/
│       ├── (site)/          # صفحات عمومی (خانه، سفرها، لیدرها، ورود)
│       ├── panel/           # پنل مسافر / لیدر / مدیر
│       ├── payment/         # صفحه نتیجه پرداخت + درگاه آزمایشی
│       └── api/payment/     # initiate + callback (زرین‌پال)
└── .env                     # تنظیمات (دیتابیس، زرین‌پال، راز نشست)
```

### گردش کار وضعیت‌ها

**سفر:** `draft → pending (تأیید مدیر) → approved → published (بارگذاری لیدر) → completed`
همچنین: `rejected` (قابل ویرایش و ارسال مجدد) و `cancelled` (توسط مدیر)

**رزرو:** `pending (لیدر) → approved → paid (زرین‌پال) → completed`
همچنین: `rejected` توسط لیدر و `cancelled` توسط مسافر/لیدر/مدیر

### پایگاه داده

SQLite از طریق Prisma (برای راه‌اندازی بدون پیکربندی). برای تولید می‌توانید به PostgreSQL مهاجرت کنید — فقط `datasource` در `schema.prisma` را تغییر دهید.

## 🖨 چاپ صفحات

دکمه «چاپ صفحه» در همه صفحات پنل موجود است. استایل‌های `@media print` منوها و دکمه‌ها را پنهان کرده و سند تمیز (مثلاً **برگه رزرو** با کد پیگیری، اطلاعات مسافر، مبلغ و خط امضا) تولید می‌کند.
